# Nabaki Afrika Ltd — Corporate Web Application

A responsive, accessible, multi-lingual corporate landing page for Nabaki Afrika Ltd, Tanzania's premier supplier of construction materials.

## Live Demo
- **Deployed Link**: [https://nabaki-afrika-demo.netlify.app](https://nabaki-afrika-demo.netlify.app)

## Key Technical Features
- **Mobile-First & Fully Responsive**: Designed for viewports down to 320px width using clean CSS `rem` scaling and custom min-width media queries.
- **Accessibility & SEO Compliant**: Built following strict WCAG / ADA standards (single `<h1>`, logical heading order, screen reader landmarks, and ARIA bindings).
- **Inline Accessible Form UX**: Features field-level validation error messages with preservation of input fields upon failure. Uses standard `autocomplete` attributes.
- **Cross-Browser Mobile Safari Fixes**: Utilizes dynamic `-webkit-fill-available` viewports to mitigate iOS browser search bar jumps.
- **Bilingual Interface**: Built-in English and Swahili translation layer in vanilla JavaScript.

## Tech Stack
- HTML5 (Semantic Architecture)
- CSS3 (Flexbox, CSS Grid, Custom Variables)
- JavaScript (Vanilla ES6)
- Netlify Forms Integration
